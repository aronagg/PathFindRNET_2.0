# Revised Data and Code Availability

The revised study is designed for reproducible release of code, configuration
files, frozen split manifests, compact result tables, reference-label protocols,
homography correspondence tables, calibration diagnostics, model-selection
manifests, final metrics and generated figures.

Raw video redistribution is not assumed. If the original dataset license permits
redistribution, the manuscript should cite the official dataset source and
archive only derived artifacts allowed by that license. If redistribution is not
permitted, the release should include scripts and manifests that reproduce the
processed artifacts from locally obtained source data.

Google-derived or other third-party map imagery should not be redistributed
unless the author confirms license, attribution and metadata requirements. Where
necessary, manuscript figures should use source video frames, author-created
schematics, or permitted map-derived graphics.

Planned public-release items:

- source code for preprocessing, target estimation, HG-SMG-TC, evaluation and
  synthesis;
- frozen protocol and configuration hashes;
- split manifests and checksums;
- polygon-reference protocol and generated reference labels where allowed;
- homography point correspondences, matrices, residuals and quality metrics;
- compact CSV/Parquet result tables;
- figure-generation scripts and final figures;
- README, data dictionary, provenance notes and reproduction commands.
