# Public GitHub Release Scope

This branch is intended for public reproducibility, not for journal submission
administration.

## Included

- publication-specific reproducibility code;
- configuration files;
- frozen protocols and protocol hashes;
- compact result tables;
- final evidence figures;
- human-defined polygon-rule-based reference-label protocol and summaries;
- homography correspondence, calibration-quality and sensitivity summaries;
- data-availability documentation;
- artifact manifests;
- OneDrive folder link and release-content descriptions.

## Excluded

- clean revised manuscript DOCX files;
- tracked-changes/redline manuscript files;
- original submitted manuscript files;
- point-by-point reviewer response letters;
- cover letters;
- private submission checklists;
- private Hungarian executive summaries;
- raw third-party map imagery unless redistribution rights are verified.

The submission-only package generated in Task 18 remains a private local
submission artifact. It should not be merged into the public release branch.

## Data Availability Boundary

The GitHub repository contains compact reproducibility artifacts. Large
redistributable data artifacts are referenced through the public OneDrive folder.
Task 17 locally staged and checksum-verified the P0 OneDrive release materials,
but final cloud synchronization and public visibility still require manual
verification through OneDrive.

The release does not claim that true raw per-frame YOLOv11 detector exports are
available, because the Task 17 audit did not find such exports.
