# Google Imagery and Provenance Statement

Some homography calibration workflows used top-view map imagery for manual point
pair selection. Any Google Maps, Google Earth, satellite imagery, map screenshots
or derived raster images are treated as restricted until licensing, attribution
and redistribution permissions are manually confirmed.

The public release should therefore:

- publish numeric calibration correspondences, matrices and residual summaries;
- avoid redistributing Google-derived rasters;
- use source video frames, author-created schematic diagrams or permitted map
  alternatives for public figures;
- include attribution and metadata only after the source and license are
  verified;
- avoid legal claims beyond documented provenance evidence.

Manuscript wording should state that homography calibration used manually
selected point correspondences and that third-party imagery provenance was
audited. It should not imply that Google-derived imagery is part of the public
redistributable dataset.
