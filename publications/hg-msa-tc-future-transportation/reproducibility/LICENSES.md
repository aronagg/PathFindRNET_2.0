# Licensing and Redistribution Notes

This file records release constraints; it is not legal advice.

- Repository code: retain the repository's governing software license and notices.
- Traffic Node Video Dataset recordings: redistribute only when the source terms
  explicitly permit it; otherwise publish access instructions and checksums.
- Derived trajectory/features: release subject to source-dataset terms, privacy review,
  and archive limits.
- Google-derived top-view rasters: do not redistribute while rights and attribution
  metadata remain incomplete.
- Homography correspondence coordinates, matrices, checksums, and author-created
  schematic/blank-coordinate views: planned for release as reproducibility metadata.
- OpenStreetMap-derived replacements, if later produced, must carry applicable ODbL
  attribution and must not be presented as the original calibration raster.
- Scholarly references remain governed by publisher/arXiv terms; this repository stores
  citations and links, not copied articles.

Every release artifact receives a license/provenance field in the artifact manifest.
