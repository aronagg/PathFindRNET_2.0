# Licenses and Provenance

## Repository Code

The repository-level license applies to source code unless a subdirectory states
otherwise. Check the root `LICENSE` before public release.

## Publication Package

The publication-specific package contains code, documentation, compact result
tables and figures generated from local research outputs. Before release, confirm
whether all included generated artifacts may be distributed under the repository
license or require a separate data license.

## Traffic Node Video Dataset

Raw videos and source dataset materials are governed by the dataset's own license
or access terms. This package does not redistribute raw videos.

## Human-Defined Polygon-Rule Reference Labels

The polygon definitions and deterministic rule-generated reference labels are
derived research artifacts. They may be suitable for DOI archive release if this
is consistent with the underlying dataset terms and institutional policy.

## Google or Third-Party Map Imagery

Google Maps, Google Earth, satellite imagery, map screenshots and any derived
raster imagery require manual license and attribution review. Do not include
these rasters in a public release unless redistribution rights are confirmed.
Use calibration-coordinate tables and author-created schematic figures instead
where possible.

## Citation

Use `CITATION.cff` and the final manuscript citation after publication. Until a
DOI archive exists, use `[DOI to be added after archive deposit]`.
