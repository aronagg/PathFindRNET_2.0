Overview

Traffic Node Video Dataset 2.0 extends the previously published Traffic Node Video Dataset. The new version reprocesses the video material with a YOLOv11x-based detection stage, replaces the earlier tracking stage with a YOLO-based tracking workflow, and adds map-based geometric correction for producing spatially more interpretable trajectory records.

Main contributions

  • YOLOv11x-based vehicle and road-user detection.
  • YOLO-based multi-object tracking workflow.
  • Trajectory filtering, filling, and smoothing tools.
  • Homography-based map correction using control points.
  • Perspective transformation tool for top-view visualization.
  • Reproducible examples through Jupyter notebooks.

Processing pipeline

Video input YOLOv11x detection YOLO tracking Trajectory database Filtering + filling Homography correction Visualization + export

Software tools

Dataset loader

Loads video-level, detection-level, and trajectory-level records into Python for analysis.

Trajectory visualizer

Plots raw, filtered, smoothed, and corrected trajectories for selected scenes.

Filtering tool

Removes short, noisy, parked, or application-specific irrelevant trajectories.

Filling and smoothing

Interpolates missing detections and smooths the motion path for stable trajectory features.

Homography transformation

Transforms image-plane trajectories into a map-aligned spatial coordinate representation.

Perspective tool

Supports manual point selection and perspective-transformed visualization of traffic scenes.
