Traffic Node Video Dataset 2.0 - Sample Code

This page lists the executable sample scripts and notebooks added for the dataset website.

Core scripts

FileTopic
examples/load_dataset.pyDataset manifest loading.
examples/plot_trajectories.pyTrajectory plotting.
examples/apply_homography.pyBasic homography transform.
examples/generate_summary_stats.pyPer-track summary statistics.

Extended scripts

FileTopic
examples/filtering_examples.pyLength, class, low-motion and application-based trajectory filtering.
examples/filling_and_smoothing_examples.pyMissing detection filling, hidden-object handling, speed/acceleration and bounding box smoothing.
examples/homography_extended_examples.pyHomography estimation, inverse projection and reprojection error calculation.
examples/isotropic_normalization_examples.pyScene-level and track-level isotropic coordinate normalization.
